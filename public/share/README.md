# Share card assets

공유 카드 배경 이미지는 이 디렉터리 한 곳에서만 관리합니다.

현재는 `default.svg` 1개만 사용합니다.

향후 타입별 이미지를 추가할 때도 코드에 이미지를 흩어놓지 않고 이 디렉터리에만 추가합니다.

예정 규칙:

- `default.*` — 기본 대표 이미지
- `boundary.*` — 책임/경계 계열
- `refusal.*` — 거절 계열
- `push.*` — 재촉 계열
- `counter.*` — 반박 계열
- `schedule.*` — 일정 계열

파일명은 UI 문구나 프리셋 이름과 직접 결합하지 않습니다. 공유 카드 타입을 결정하는 매핑은 코드의 단일 레지스트리에서 관리합니다.

이미지가 늘어나기 전까지는 `default.svg` 외의 이미지 파일을 추가하지 않습니다.
